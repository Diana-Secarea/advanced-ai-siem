SELF-SUPERVISED BY DESIGN

No human ever labels an alert.

🌲 Isolation Forest — contamination='auto'

Fitted on all 2,171 alerts with no label filter. It makes no assumption about the proportion of anomalies — genuinely unsupervised.

🧠 Autoencoder — one-class + self-trim

Trained only on clean traffic, then re-purified: fit → drop the 10% worst reconstructions (mislabelled attacks) → refit. It learns the normal manifold; attacks reconstruct badly.

👤 UEBA — behavioral baselines

Profiles every user, host and source IP from clean traffic: active hours, typical rules, level history. Unknown users, rare hours, level escalations and new user-host pairs score high.

⚖ Learned stacking — the only supervised layer

A logistic regression on top of the three scores learns how much to trust each model — no hardcoded weights. On the held-out test set it learned to lean on UEBA and the autoencoder, keeping the isolation forest as a low-weight safety net.

ADVERSARIAL SELF-TRAINING

Attacker-in-the-loop — mine the blind spots.

A budget-constrained agent generates synthetic alerts that stay real attacks (the same oracle that labels the training set) yet are tuned to slip past the ensemble. Every attack that scores NORMAL is a false negative the detector has never caught — banked as retrain data. Harvest them back in and the detector learns from what it missed.
